## Product principles

1. **Real, never invented:** versions, downloads, completion metrics, analytics, and build status must be traceable to specific sources.
2. **Public and private stay separate:** no owner-only data, tokens, private notes, or unreleased artifacts can enter a public website bundle.
3. **Release-gated:** do not label a binary approved or verified without recorded source, immutable asset identity, signing review, QA and owner approval.
4. **Design approval first:** use actual browser screenshots on desktop/mobile before merging major UI changes.
5. **Performance and accessibility are core:** reduced motion, mobile adaptability, keyboard navigation, focus clarity, and source-correct empty/error states.
6. **Zero-cost-first:** verify free usage limits, privacy terms, and risks before choosing a service; no automatic spending.
7. **Project isolation:** changes to NAVIN STUDIO do not alter individual app or game repositories.
