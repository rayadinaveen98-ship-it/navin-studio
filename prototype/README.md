# Web Platform Prototype v0.1

**Status:** Working interactive design prototype. Not approved for production.

## Open the prototype
Open [prototype/index.html](./index.html) using a modern browser. It is a **standalone, self-contained HTML document** with inline CSS, JavaScript and bundled image assets. No dependencies, build step, backend, accounts or payments required.

### Test the experience
- Explore the cinematic **Home** experience and category rail.
- Open **Creations**, choose category filters and inspect project-detail dialogs.
- Use **Search** via the header or keyboard `/` / `Ctrl+K`.
- Visit **Updates** for an honest no-approved-releases state.
- Browse **Studio** philosophy and **Journal** milestones.
- Resize the browser for responsive **web** layouts (not the separate native mobile app).

## Trust and scope
All eight projects are editorial development previews. They **do not** imply published/stable builds. No invented APK names, versions, install links, traffic analytics, QA results or private milestones are shown. All source links point to known public repositories.

**Not included:** private dashboard, native mobile app, backend, GitHub release synchronization, sign-in, analytics or AI assistant.
